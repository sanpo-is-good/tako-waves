# TAKO WAVES

20穴のたこ焼き器を、上からの映像で演奏するオーディオヴィジュアル楽器です。VDO.Ninjaの遠隔映像、端末のカメラ、画面上の20パッドから入力できます。

## 実機セットアップ

1. たこ焼き器全体を真上から、固定したカメラで映します。串の影が見える程度に、斜め前から柔らかく照明を当てます。
2. VDO.Ninjaの送信側で任意のストリームIDを作り、画面の「VDO.NINJA 接続」に視聴URLまたはIDを入力します。
3. 「四隅を合わせる」を押し、左上 → 右上 → 右下 → 左下の順に、角にある穴の中心をクリックします。
4. 串や手を映像から外して「基準を記録」を押します。
5. 串で穴に触れ、誤検出がある場合は感度の数値を上げます。反応しづらい場合は数値を下げるか、検出範囲を広げます。

## 20穴のフレーズ

- 1行目: キックラン、スネアドラッグ、ハットスキップなどのドラムフィル
- 2行目: ウォーク、バウンス、上昇、シンコペーション、ドロップのベースリフ
- 3行目: パルス、アルペジオ、上昇・下降などのコードフレーズ
- 4行目: コール＆レスポンス、スパーク、オービット、カスケードの旋律

各穴は単音ではなく4〜8音の短いフレーズを再生します。入力は標準で16分音符へ揃い、常時鳴る4小節のドラム・ベース・コードBGMへ同期します。`BGM ON/OFF`で伴奏を切り替え、`REC 2 BAR`で32ステップの演奏を記録できます。

## 安定検出のコツ

- カメラとたこ焼き器を動かさない
- 自動露出が暴れにくい、均一な照明にする
- 木串や竹串の先を濃い色にすると検出しやすい
- 実演中に照明が変わったら、もう一度「基準を記録」する

VDO.Ninjaのフレーム取得は埋め込みAPIを利用します。ネットワーク状況によって映像入力に遅延が出る場合は、この端末のカメラ入力が最も低遅延です。

## ローカル確認

`npm run dev` を実行し、表示された `http://localhost:5173/` をブラウザで開きます。HTMLファイルを直接開く方法では、音とスクリプトが正しく読み込まれません。
